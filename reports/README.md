# reports/

Report-ready outputs from `verasonus.evaluation.reports` are saved here and committed, so the
final report and slides always use the latest numbers.

- `figures/`: PNG (300 dpi) and PDF figures
- `tables/`: CSV tables

Name files after what they show, e.g. `roc_seen_generators.png` or `robustness_by_edit.csv`.
Report results as they are. If numbers look too good, look for shortcuts before using them.
