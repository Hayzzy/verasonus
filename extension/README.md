# VeraSonus Chrome extension (Phase 4 skeleton)

> **Not active yet.** This is an empty Manifest V3 skeleton. Real work starts in Phase 4,
> after the web prototype works end to end.

**Plan:** capture 10–20 seconds of the current tab's audio with `chrome.tabCapture` and an
offscreen document, send it to the VeraSonus API, and show the verdict in the popup. Streaming
services already compress tab audio, so the lossy-codec robustness tests in the main project
matter here.

| File | Role |
|---|---|
| `manifest.json` | Manifest V3: popup, module service worker, `tabCapture` + `offscreen` permissions |
| `popup.html`, `popup.css` | Popup UI in the slide palette |
| `offscreen.html` | Page that will record tab audio (service workers cannot) |
| `src/*.ts` | TypeScript sources, compiled to `dist/` by `npm run build` |
| `icons/` | Generated by `scripts/make_icons.py` in the main project |

## Try it

```bash
cd extension
npm ci
npm run build
```

Then open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked** and choose
this `extension/` folder.

When the API is called in Phase 4, add its URL to `host_permissions` in `manifest.json`.
